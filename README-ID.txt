LAST SIGNAL — BUILD 0.3.0

PEMBARUAN
- Main menu baru: Player Identity, Play Game, Continue Story, Chapter Epilogues, Developer Information, Support Developer.
- Continue Story nonaktif jika belum ada progres.
- Epilogue Chapter 01 terbuka setelah pemain mencapai Scene 06.
- Informasi developer dan dukungan developer tersedia sebagai panel informasi. Pembayaran QRIS belum diaktifkan.
- Penyimpanan lokal tetap digunakan pada versi ini.
- Cache PWA diperbarui ke last-signal-v030.

CARA UPDATE GITHUB
1. Ekstrak ZIP.
2. Upload/ganti semua file di dalam folder LAST_SIGNAL_PWA_V02 ke root repository GitHub (jangan upload folder induk sebagai satu folder bertingkat).
3. Pastikan folder story dan assets/icons ikut terunggah.
4. Commit ke branch main.
5. Tunggu GitHub Pages selesai deploy, lalu buka ulang website.

CATATAN
Versi ini masih prototype frontend. Progress tersimpan di browser/perangkat yang sama, belum tersinkron ke cloud. Fitur pembayaran belum aktif dan belum ada transaksi nyata.
